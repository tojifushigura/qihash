# Code of Conduct

## Our pledge

We as contributors and maintainers pledge to make participation in qiHash a respectful and harassment-free experience for everyone.

## Expected behavior

Participants are expected to:

- Be respectful and constructive.
- Focus criticism on ideas and code, not people.
- Assume good intent where reasonable.
- Accept maintainer decisions about project scope and security posture.
- Avoid exaggerated security claims without evidence.

## Unacceptable behavior

Unacceptable behavior includes:

- Harassment, threats or personal attacks.
- Discriminatory language or behavior.
- Publishing private information without consent.
- Spam, trolling or repeated off-topic arguments.
- Pressuring maintainers to make unsafe security claims.

## Security discussion rule

qiHash is a cryptographic/security project. Strong criticism of the design is welcome when it is technical, evidence-based and respectful. Personal attacks are not acceptable.

## Enforcement

Maintainers may remove comments, close issues, block users or reject contributions that violate this Code of Conduct.

## Reporting

Report conduct concerns privately to the repository maintainer. Security vulnerabilities should be reported according to [`SECURITY.md`](SECURITY.md), not through public issues.
